---

## ✨ Можливості

### 📊 Dashboard (Панель керування)
- Реальний час: CPU, доступна RAM, заряд і здоров’я батареї
- Загальна оцінка здоров'я системи
- Швидкий огляд всіх компонентів

### 💻 Mac Діагностика
- 🔋 Батарея — здоров'я, цикли, температура, напруга, рекомендації
- 💻 CPU — модель, ядра, навантаження в реальному часі
- 🎮 GPU — модель, Metal, кількість ядер
- 🧠 RAM — доступна пам'ять за оцінкою macOS, тип і тиск пам'яті
- 💾 SSD — SMART статус, використання, файлова система
- 🖥 Дисплей — роздільна здатність, Retina
- ⚙️ Процеси — топ-процеси по CPU/RAM, PID

### 📱 iPhone Діагностика
- Модель, серійний номер, IMEI, iOS і статус активації — після підтвердження «Довіряти»
- Поточний заряд і сховище, якщо їх надає пристрій
- Локальний бекап у папку, яку обирає користувач; історія бекапів зберігається локально
- Підтримка через `libimobiledevice`; дані не надсилаються в хмару

> iOS не надає «Maximum Capacity» батареї та повну файлову систему через стандартний USB-протокол. MacHealth чесно показує «Недоступно», а не вигадане значення.

### 🌐 Мережеві інструменти
- 📡 Wi-Fi аналіз (SSID, сигнал, канал, швидкість)
- 🏎️ Speed Test (реальні download і ping; upload не імітується без тестового сервера)
- 🔍 Ping будь-якого хоста
- 📋 Сканер локальної мережі (ARP scan)
- 🌍 Зовнішня IP-адреса

### 🔌 USB Monitor
- Автоматичне виявлення USB пристроїв
- VID/PID, серійний номер, швидкість, виробник

### 🧪 Hardware тести
- 💾 Локальна швидкість I/O тимчасового файлу (результат залежить від кешу macOS)
- 🌐 Мережева затримка
- 🔍 DNS швидкість
- 🧠 Стан і тиск пам'яті macOS

### 📋 Звіти
- Генерація повного текстового звіту
- Збереження у файл або копіювання в буфер

## 📥 Встановлення

1. Завантажте `MacHealth.zip` з [Releases](../../releases/latest)
2. Розпакуйте
3. Перемістіть `MacHealth.app` в «Програми»

### ⚠️ Перший запуск

```bash
xattr -cr /Applications/MacHealth.app
```

Або: ПКМ на програмі → «Відкрити» → «Відкрити»

### Wi‑Fi дані

Для відображення назви Wi‑Fi мережі (SSID), BSSID та рівня сигналу macOS попросить дозвіл на геолокацію. Це вимога macOS: застосунок використовує дозвіл лише для читання параметрів поточного Wi‑Fi-з’єднання.

### Розробка та збірка з вихідного коду

Потрібен повний **Xcode 15.4 або новіший** (самих Command Line Tools недостатньо для SwiftUI-макросів).

```bash
git clone https://github.com/XOTT69/MacHealth.git
cd MacHealth
open MacHealth.xcodeproj
```

У Xcode виберіть схему `MacHealth` і натисніть **Run**. У CI застосунок збирається автоматично після push у `main` або за тегом `v*`.

### 📱 Для iPhone діагностики

```bash
brew install libimobiledevice
```

- SwiftUI (macOS 13+)

- libimobiledevice (iPhone)
- GitHub Actions (автоматична збірка)

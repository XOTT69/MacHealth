## 📖 Опис

**MacHealth** — це безкоштовна macOS програма, яка проводить повну діагностику вашого MacBook та підключеного iPhone, подібно до інструментів сервісних центрів. Програма аналізує стан компонентів і надає рекомендації щодо ремонту та обслуговування.

## ✨ Можливості

### 💻 Діагностика MacBook
- 🔋 **Батарея** — здоров'я, цикли заряду, температура, рекомендації по заміні
- 💻 **Процесор** — модель, ядра, навантаження, температура
- 🎮 **Графіка** — GPU, Metal підтримка
- 🧠 **Оперативна пам'ять** — використання, тип, вільний обсяг
- 💾 **Сховище** — SSD/HDD стан, SMART-статус, файлова система
- 🌐 **Мережа** — Wi-Fi, Bluetooth, IP-адреса
- 🖥 **Дисплей** — роздільна здатність, тип (Retina)

### 📱 Діагностика iPhone (через USB)
- Модель, серійний номер, IMEI
- Версія iOS
- Стан батареї та здоров'я
- Обсяг пам'яті
- Статус активації

### 📋 Звіти та рекомендації
- 🟢 Зелений — все в нормі
- 🟡 Жовтий — потребує уваги
- 🔴 Червоний — критично, потрібен ремонт
- 💰 Орієнтовна вартість ремонту
- 📄 Експорт звіту у TXT файл

## 📥 Встановлення

### Спосіб 1: Завантажити з Releases
1. Перейдіть на сторінку [Releases](../../releases)
2. Завантажте `MacHealth.zip`
3. Розпакуйте архів
4. Перемістіть `MacHealth.app` в папку **Програми** (`/Applications`)

### Спосіб 2: Зібрати з коду
```bash
git clone https://github.com/xott/MacHealth.git
cd MacHealth
xcodebuild -project MacHealth.xcodeproj -scheme MacHealth -configuration Release build
```

## ⚠️ Перший запуск (важливо!)

Оскільки програма не підписана сертифікатом Apple Developer, macOS може показати попередження. Ось як це обійти:

### Варіант A: Через контекстне меню
1. Натисніть **правою кнопкою** миші на `MacHealth.app`
2. Виберіть **«Відкрити»**
3. У вікні попередження натисніть **«Відкрити»**

### Варіант B: Через Системні налаштування
1. Спробуйте відкрити програму подвійним кліком
2. Перейдіть до **Системні налаштування → Конфіденційність та безпека**
3. Внизу побачите повідомлення про MacHealth — натисніть **«Все одно відкрити»**

### Варіант C: Через Термінал
```bash
xattr -cr /Applications/MacHealth.app
```

> 💡 **Це безпечно!** Попередження з'являється для ВСІХ програм без сертифіката Apple ($99/рік). Код програми повністю відкритий — ви можете перевірити його самостійно.

## 📱 Діагностика iPhone — додаткова настройка

Для повної діагностики iPhone необхідна бібліотека `libimobiledevice`:

```bash
# Встановіть Homebrew (якщо ще не встановлено)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Встановіть libimobiledevice
brew install libimobiledevice
```

Після встановлення:
1. Підключіть iPhone через USB-кабель
2. Розблокуйте iPhone
3. Натисніть «Довіряти» на iPhone
4. Запустіть MacHealth → вкладка «Діагностика iPhone»

- **libimobiledevice** — зв'язок з iPhone
- **GitHub Actions** — автоматична збірка

# Архітектура MacHealth

MacHealth — локальний macOS-застосунок для діагностики Mac і авторизованих iPhone/iPad.

## Принципи даних

- Значення показуємо лише тоді, коли його повернуло джерело даних.
- `—` або «Недоступно» означає, що macOS/iOS не надала показник, а не нульове значення.
- Для кожної небезпечної дії потрібне окреме підтвердження користувача.
- Дані пристроїв не передаються на сервери MacHealth.

## Шари

- `App/` — запуск застосунку.
- `Models/` — типізовані моделі UI та діагностики.
- `Services/` — отримання даних через системні API macOS або встановлені локальні інструменти (`libimobiledevice`).
- `Views/` — SwiftUI-інтерфейс без shell-логіки.
- `Core/` — спільні безпечні утиліти та форматування.

## Межі iOS

iOS не відкриває повну файлову систему та деякі приватні метрики (наприклад, Maximum Capacity батареї) звичайному macOS-застосунку. MacHealth не обходить ці обмеження: доступні дані отримуються через довірене USB-з’єднання та локальний авторизований бекап. Папки бекапів обирає користувач; застосунок сканує лише збережені ним папки і тільки власну структуру `MacHealth Backups/<UDID>`.
